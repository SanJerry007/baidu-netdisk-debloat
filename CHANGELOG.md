# Changelog

## 1.0.0 (2026-11-25)

First release, for Baidu Netdisk 8.2.1.102 only.

### Added

- `BaiduNetdiskDebloat.ps1`, generated by [app-debloat](https://github.com/DaizeDong/app-debloat): dry run by default, `-Apply`, `-Install` (re-apply at logon and every 6 hours through the task `BaiduNetdiskDebloat-Watch`) and `-Uninstall` (replays the journal in reverse).
- Default actions: block the client updater `AutoUpdate\Autoupdate.exe` and the kernel updater `kernelUpdate.exe` with same-named placeholder directories, deny writes to the `AutoUpdate` folder for the current user, outbound firewall rules for `crashpad_handler.exe` and the log uploader `HelpUtility.exe`, and placeholder directories for the Office add-in DLLs `YunOfficeAddin.dll` and `YunOfficeAddin64.dll`.
- Options, all off by default: `-RemoveStagedUpdate`, `-RemoveSpeechSdk`, `-RemoveAiEngine`, `-DisableUtilityService`, `-BlockBugReport`, `-BlockDiagnoseUpdater`, `-BlockOfficeAddinPolicy`, `-RemoveOverlays`, `-BlockInboundP2P`, `-MuteNotifyService`, `-RemoveAiMsix`, `-HideContextMenu`, `-CleanOpenWith`, `-BlockBrowserExtension`.
- Version check: `-Apply`, `-Install` and `-Auto` refuse any version other than 8.2.1.102 (exit code 2) unless `-Force` is given.
- `docs/how-it-works.md`: launch chain, gates, re-install vectors, cross-app hijacks, evidence levels, durability tests and known limitations.
